# Suporte

## Onde buscar ajuda

| Preciso de… | Onde ir |
|---|---|
| Relatar um bug no app | [Nova issue de bug](https://github.com/in100tiva/mvp-vale/issues/new?template=bug_report.yml) |
| Sugerir uma melhoria | [Nova issue de melhoria](https://github.com/in100tiva/mvp-vale/issues/new?template=feature_request.yml) |
| Entender como rodar/contribuir | [CONTRIBUTING.md](CONTRIBUTING.md) |
| Relatar falha de segurança | [SECURITY.md](SECURITY.md) — canal privado |
| Contato profissional | [github.com/in100tiva](https://github.com/in100tiva) |

## Antes de abrir uma issue

1. Confira o [README](README.md), especialmente **Rodando localmente** e **Scripts**.
2. Verifique se o problema acontece em `main` e se já existe issue parecida.
3. Rode `npm ci && npm run lint && npm run build` — se falhar aí, cole a saída do terminal na issue.

## Escopo do suporte

Este é um projeto de portfólio mantido por uma pessoa, em tempo livre. Não há SLA: issues são respondidas conforme disponibilidade, com prioridade para bugs de segurança e regressões.
